# clipio/ui/
The panel, written in QML (Qt Quick) and loaded by the panel process (`clipio/panel.py`).

- `Setup.qml` — the setup window of the packaged app: logo pieces settle in, a pencil line shows progress, a check mark and paper scraps mark success
- `Main.qml` — the frameless, transparent, always-on-top window that holds the panel
- `components/` — panel, cards, dialogs, theme and helpers
- `icons/` — white SVG icons tinted at runtime
- `assets/` — logo
