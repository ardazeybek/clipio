# ui/components/
QML bileşenleri.

- `qmldir` — tekil (singleton) ve bileşen kayıtları
- `Theme.qml` — kağıt teması renkleri, font seçimi, ölçüler (tek kaynak)
- `Strings.qml` — Türkçe/İngilizce kısa metinler
- `Store.qml` — state.json okuma, süzme (Tümü/Metin/Resim/Sabit), ListModel farkı, eylemler, biçimlendiriciler
- `Panel.qml` — ana panel: sürüklenebilir kağıt sayfa, başlıkta logo, arama + duraklat/temizle/ayarlar, sekmeler, liste, temizleme onayı ve ayarlar pencereleri, klavye, açılış animasyonu
- `ClipCard.qml` — tek not kartı: türe göre içerik, zaman, üzerine gelince sabitle/sil, animasyonlar
- `Tabs.qml` — kayan bant çizgili yazı sekmeleri
- `EmptyState.qml` — boş liste görünümü (süzülen logo)
- `Icon.qml` — SVG simgeyi boyar
- `IconButton.qml` — yuvarlak simge butonu (tıklama zıplaması, simge değişim ve üzerine gelince dönme animasyonu)
- `Dialog.qml` — panel içi kağıt pencere (örtü + ortada not kartı)
- `PaperButton.qml` — kağıt buton: dolgulu, sade ya da seçili
