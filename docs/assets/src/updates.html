Updates

Always the newest. Zero effort.

Updates itself

1Looks for a new version at start and once a day.
2Downloads it and checks it against a checksum.
3Installs while the panel is closed. History and settings stay.
4A small note says “Clipio was updated”.

Turn it off in Settings → Features → Automatic updates. Installed with Python? You just get a note.

Leaves cleanly

Windows
Settings → Apps → Clipio → Uninstall
macOS and Linux
Run clipio uninstall

Your history and settings are kept, in case you come back.
