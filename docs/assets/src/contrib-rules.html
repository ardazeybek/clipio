Code style

Six rules that keep Clipio easy to read.

One job per folder

Its README.md lists every file in one line. Update it with your change.

Keep the map true

Update MAP.md when the main flow, a backend or a location changes.

Say what it does

A one-line comment on top of every file and every small function.

English everywhere

Code, comments, interface texts and docs.

Core stays pure

clipio/core/ never touches the OS. That goes in clipio/system/.

Theme in one place

Colors, fonts, sizes from Theme.qml, texts from Strings.qml.
