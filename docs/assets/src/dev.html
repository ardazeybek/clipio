For developers

Two small processes. Nothing hidden.

Python and Qt Quick (QML) through PySide6. Needs Python 3.10 to 3.14.

The recorder

always on · ≈ 25 MB of its own

Clipboard, saving, pasting, hotkey, tray and updates.

The panel

only while you use it, plus 5 min

The window you see. It quits by itself and gives all its memory back.

clipio/core/Sorts and stores items in SQLite. No OS code.
clipio/system/One small backend per system: clipboard, paste, hotkey, autostart, updates.
clipio/setup/The installer of the ready-made app.
clipio/ui/The panel and setup windows in QML.
packaging/Builds the installers on every release.

Tests run on Windows, macOS and Linux with Python 3.10 to 3.14 on every push. MAP.md maps the whole thing.
