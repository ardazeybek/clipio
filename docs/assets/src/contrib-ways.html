Contributing

You do not need to write code to help.

Each of these makes Clipio better for everyone.

Report a bug

What you did, what you expected, what happened.

Test your system

Windows, macOS and less common Linux desktops are extra welcome.

Fix the docs

An unclear step in a README? A one-line fix helps.

Design and access

Contrast, sizes, keyboard use and animations.

With a bug report, tell us: your system and version, your Linux desktop (for example Hyprland, GNOME on Wayland, KDE on X11), and the output of the two commands below.
