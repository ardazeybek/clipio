Workflow

From idea to merged in six steps.

1

Look first

Search the open issues. Maybe someone is on it.

2

Talk first

A bigger change? Open an issue with your idea before you start.

3

Fork and branch

For example fix/paste-in-terminal.

4

Make the change

Small and focused beats big and mixed.

5

Run the checks

The tests, then the flow by hand: copy, open, search, paste, pin, delete.

6

Open a pull request

Say what changed and why. Add a screenshot for visual changes.
