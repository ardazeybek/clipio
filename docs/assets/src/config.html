Settings file

Prefer a text file? Here it is.

Edit config.toml, then run clipio stop and clipio start.

Windows

Settings %APPDATA%\clipio\config.toml
History %LOCALAPPDATA%\clipio\

macOS

Both in
~/Library/Application Support/clipio/

Linux

Settings ~/.config/clipio/config.toml
History ~/.local/share/clipio/
